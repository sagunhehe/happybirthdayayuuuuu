# Birthday Search

A Google-style search page made as a birthday surprise. Open `index.html`, or host it with GitHub Pages
(Settings > Pages > Deploy from branch > `main` / root).

- Text, captions and places: edit the content blocks at the top of the `<script>` in `index.html`.
- Photos live in `photos/`. To add one, copy it there and add a line to `IMAGES`.
